# CPP-OOP-Practical-11

## Aim
To implement the `list` and `vector` classes of the Standard Template Library (STL) in C++ using real-life examples.

## a) List Class – Student Attendance Management System
- Uses the STL `list` container to store student roll numbers.
- Allows adding, removing, and displaying student roll numbers.
- Demonstrates basic list operations.

## b) Vector Class – Shopping Cart Management System
- Uses the STL `vector` container to store product prices.
- Allows adding and removing products.
- Displays product prices and calculates the total bill.

## Concepts Used
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- Classes and Objects
- List and Vector Containers
- Insertion, Deletion, and Display Operations

## Conclusion
This practical demonstrates the use of STL `list` and `vector` containers to manage data efficiently using real-life examples in C++.
